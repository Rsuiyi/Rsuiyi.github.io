Agent Memory 检索端:120 篇文献分析

范围:只谈检索端。
方法:6 个并行文献 agent × 六面,合计 120 篇已核实文献(2021–2026);随后跑 两轮”生成→批判→修正→再批判” 迭代。每篇给出机制+局限,给出总体局限、多跳/多角度专项分析,最终候选思想按八项标准评估(目标完成性/创新性/撞车/可证伪/相似工作/最强反例/审稿人风险/验证路线)。

0. 摘要

120 篇文献确认三件事:(1) 检索召回高(>90%)但答案 F1 低(~60%),且图检索端也复现”证据已在上下文、错在推理”(KET-RAG 后续、Recall-Is-Not-Enough)——瓶颈在利用;(2) 检索正从”写时抽取+向量 top-k”迁移到查询时重构(LazyMem/DeferMem/RippleMem),纯 embedding 相似度在时序/多跳/冲突下不够用;(3) token 效率方法几乎全是”精度-预算交换”,几乎无人做”agent 记忆 + 固定预算 + 统计保证”的组合。

两轮迭代后收敛的结论:检索端 +20% = 在固定预算、零额外 LLM 调用下,做四件事——把 cosine 校准成”答案支持概率”、用 FN=0 保守去冗余回收预算、把”选 S”做成集合级可答性的校准优化、用顺序+冲突消解增强答案模型对证据的利用;多跳保留为几何门控的零 token 图扩散,只在跨事件组合子集上主张收益。所有改进都是闭式/统计/组合优化,零 LLM、免训练(除校准需少量金标对)。

2. 问题设定与约束(数学化)

  • 约束 1:构建/检索 token 严重不对称 ⟹ 读侧任何”每查询一次 LLM”的动作都极贵;检索预算几乎全花在最终答案上下文。
  • 约束 2:高召回、低精度 ⟹ 发力点在选择与利用,不在召回。
  • 约束 3:多查询线性烧 token ⟹ 多角度必须在嵌入空间做(向量运算),不在文本空间生成句子。

自由度 = 选择函数+ 呈现方式。数学杠杆三类:相关信号校准、集合级覆盖、序贯/顺序结构。多跳/多角度不是被放弃,而是被降级为零 token 组件 + 子集定向测量(§5)。

3.6 嵌入校准与几何(18 篇)

  • 免训练/可用:CSLS (1710.04087)、白化 (2103.15316)、outlier 清零/ZCA (2306.00458)、DINOSAUR (2606.04603)、KITE (2509.15676)、Cognica 似然比校准(2026)。
  • 诊断:hub 现象 (Radovanović 2010, JMLR)、各向异性 (Ethayarajh 2019)。
  • 需训练/标签:PCME、pEBR (2025.emnlp-industry)、ERCE (2105.04651)、VBLL、KISSME、Isotonic-LTR。
  • 共性:免训练几何修正 = 全局统计、查询无关(白化/CSLS 不感知 query 局部分布);把分数变概率的都依赖标签或语料分布,跨域不可迁移;学习型方法强但动模型,对”冻结嵌入 drop-in”过重;ERCE 类排序校准评测仍小众。

4. 跨族总体局限(七条)

  1. 相关函数未校准:cos/dot 是几何角度不是概率;局部密度盲区 + hubness(事件摘要易成”万能近邻”);查询(短而指代)与记忆(长摘要)粒度错配是偏置非噪声。
  2. 集合目标缺失:top-k 选”各自最像”不选”合起来够答”;冗余是预算黑洞。
  3. 无预算会计:几乎无人量冗余率 ρ、无人报”精度 vs 不同证据”标度 η;预算花在哪不是记账对象。
  4. 无自校准:agent 自己的问答回路是免费自监督信号,没人用来校准相关函数(除 FLAIR 类通用 IR 反馈学习)。
  5. 利用-gap 未被分解:”高召回低精度”与”答案已在上下文仍推不出”是公认现象,但无人把它拆成(校准/冗余/冲突/顺序/组合)各贡献多少。
  6. 检索决策信号与答案正确脱钩:熵/阈值/自省都未与”边际信息价值”严格挂钩(3.4 共性);自适应检索出现负结果。
  7. 无保守性保证:去冗余(MMR/DPP/子模)可能删唯一证据,无人给出”删的一定可证被包含”的结构保证。

4.2^*^. 多跳与多角度的潜力与局限(专项)

4.2.1 多跳

潜力:跨实体/跨事件组合——答案需 A+B 合并,而 A、B 不靠语义相似共现。证据:LongMemEval-S 时序/组合查询上 RippleMem +11.87%;MuSiQue 干扰密集下正确机制能拉开差距(PIKE-RAG 59.6 为当前较高);HippoRAG2 的 R@5 +13.9% 主要落在 2Wiki。

局限(文献定论):

  1. LLM 逐 hop 烧 token(IRCoT ≤8 hop;Search-o1/ReAct 同理);
  2. query-blind 遍历浪费——加了门才有效(2606.30133 门消融 +3.6–7.4 F1,延迟降 1.5–4.9×);
  3. 图构建成本(构建侧,但影响索引);
  4. 基准平均稀释信号——2Wiki 吃 phrase-node、MuSiQue 吃显式路径,无普适最优;
  5. 错误逐 hop 累积;
  6. 负结果:自适应检索多数时候无益(Shakya 2026)。

思考:零 token 图算法(PPR/扩散/PCST)+ 查询级门(何时值得扩散,统计检验而非启发式)+ 子集定向测量(只在跨事件组合子集上报收益,不用全基准平均稀释)。

4.2.2 多角度

潜力:不同侧面补互补证据;IR 实证 ColBERT-PRF +26% MAP 即”多角度在嵌入空间”的收益。

局限:

  1. LLM 生成角度烧 token 且对模糊/生僻查询失败(SIGIR 2025 系统性证据);
  2. PRF 级联风险——收益依赖首轮检索质量,错一层全盘错;
  3. token 未消失只被移动(查询时→训练/首轮/索引端)。

思考:嵌入空间多角度(Rocchio/PCA/“query-as-region”)+ 预算内融合;不在文本空间生成角度。
