基于论文 MemPursuit 的解读与简单实验分析

论文：Recall What Is Missing: Composing Evidence from Long-Term Agent Memory（Qi Feng, Jicong Fan, CUHK-Shenzhen）
代码：https://github.com/FengQi‐HITSZ/MemPursuit
本文档尝试介绍这个论文的产生背景问题，把每一个公式的符号认全、把每个公式在算什么讲清楚、对照代码看它实际怎么实现的，同时基于论文数据和自己的数据给出分析。

这篇论文想解决什么

  • 现在基于分数选出top-k个证据的方式实际上是将某条记忆的有用性视为独立于其他选定记忆之外。但在在较长的历史记录中,彼此独立相关的记 忆往往会重复同一事件、偏好或对话事实；而多跳查询 可能会得到某一跳 的多个改写表述,却遗漏完成证据链所必需的一个相似度较低的事实；选择增加K值会消耗更多上下文,使读取器接触到更多干扰项,并削弱选择性记忆层的作用。
  • 基于图的系统已经能够通过显式关系结构支持跨记忆检索，构建和维护这些结构需 要额外的操作;随着记忆规模增长,全图整合已被认为是开销的重要来源。

所以这篇论文想要提出一种 无需额外的语言模型评分或交叉编码器评分、并且更高效省资源的查询方法。

2. Eq. 1 — 理想目标

【公式】

【符号】

  • 注意是集合的效用，不是逐条效用之和

【说明了什么】

但它不可计算：回答质量在选择时未知。

论文紧接着指出：逐条打分（Top-K）是在近似一个加性目标

加性目标的根本缺陷：每条记忆的贡献与其他选择无关。于是它表达不了两件事：

  1. 重叠时应该打折——两条记忆讲同一件事，第二条的边际贡献远小于第一条
  2. 互补时应该加分——两条单独看都不够，合起来才构成证据

这就是这篇论文要解决的问题：找一个能评估”联合”的可计算目标。

3. Eq. 2 — 稀疏查询重构（★全文的核心转换）

【公式】

【符号】

符号含义
$\alpha_m$记忆 $m$ 在重构查询时的权重
非零权重的个数
$\lambda$岭系数

【它在干什么】

用最多 $K$ 条记忆的非负凸组合，去”拼”出查询向量。

【四个约束各自防什么】

约束防止什么
$\alpha \succeq 0$防止用一正一负抵消来”假装修好了”（如 $\alpha_1=100,\ \alpha_2=-99$）
$\sum \alpha_m = 1$防止无限缩放（否则 α 可任意放大，重构向量失控）
预算：只能用 $K$ 条
$\lambda > 0$记忆重叠时稳定解（Gram 矩阵可能奇异）

【为什么这个替代是合理的】

论文的直觉：

如果一小撮记忆能”拼”出查询，说明它们合起来覆盖了查询所指向的信息。

  • 相似的记忆提供相似的重构方向 → 冗余
  • 互补的记忆才能把联合重构拉近查询

【关键性质】

$|\alpha|_0 \le K$ 让这个问题是组合优化（NP-hard）。

但——一旦把支撑集 $S$ 固定，它就退化成凸二次规划（QP）。所以可以”先定集合、再解权重”交替进行。

【⚠️ 一个必须点明的建模假设】

Eq. 2 重构的是”查询向量”，不是”回答所需的信息”。

这是一个 surrogate（替代目标）。它的正当化来自后面的 Proposition 1——在 fact-cluster 模型下，残差导向的贪心恰好选出”每个必需事实一个代表”。

但那是理论上的正当化，不是经验上的。 经验上的支持是实验表。读这篇时要记住这一点：“能重构查询”和”能回答问题”不是同一件事，论文是用一个理论模型把两者接起来的。

5. Eq. 4 — UMP 分（★全文最重要的一个式子）

【公式】

【展开看就懂了】

【说明了什么】

★ 候选分 = 「它和查询有多像」 − 「它和已经选中的东西有多像」。

这就是去冗余的全部机制，一行公式说完了：

  • 一条记忆即使和查询很像，如果已选记忆也覆盖了同一个方向 → 第二项大 → 净分被压下去
  • 一条记忆即使和查询不像，但那个方向还没被覆盖 → 第二项小 → 净分相对高

【论文 Figure 2 的例子】

查询要两个 adoption dates：

  • 已经选了 Buddy 的记录
  • Toby 的记录虽然查询相似度更低，但因为 Buddy 没覆盖 Toby 那个方向 → Toby 被选中

【论文给的理论解释】

原文：

Because an unselected memory has zero weight, this score equals the negative derivative of the objective in Eq. 2 with respect to its coefficient.

也就是说：

它是”把这条记忆的系数从 0 挪动一点点时，目标下降的速率”。

所以它是”加进去能带来多大改进”的一阶判据——不需要对每个候选真跑一次重拟合。

⚠️ 注意：用 $U$ 开头容易让人以为它是个”效用值”，但严格说它是边际改进率。越大越好，因为加进去是让目标下降。

【公式】

【符号】

【它说什么】

如果一条候选 $m$ 在已选集合的凸包附近（距离 ≤ δ），那它的 UMP 分被”已选集合内部的最高分 + δ·‖r‖”所界定。

反过来：只要某条候选超过这个上界，它就一定在凸包的 δ-邻域之外——即指向一个结构上新的方向。

在这个模型下：

位置含义

于是：

残差导向的贪心 = 优先补还没覆盖的事实，而不是在已覆盖的事实上重复花钱。

13. Eq. 17 — Assumption B.1：覆盖边际

【模型的四条假设】

候选集被划分成：

假设数学形式直觉
1. 簇内集中，同一事实的记忆彼此很近
2. 簇间相似，不同事实之间有基础相似度 $\rho$
3. 查询相关性均衡，每个必需事实都和查询相关
4. 干扰项分离，干扰项和查询不太相关，但和相关项像

【覆盖边际（Eq. 17）】

【符号】

符号含义
$\rho$簇间基础相似度（要低）
$h$必需事实个数
查询对各事实相关度的不均匀程度
$\eta$相似度噪声容差
$\varepsilon$簇内离散度
$\gamma$干扰项与相关项的间距

【直觉】

  • $\dfrac{1-\rho}{h-1}$ 是”事实之间应该有的区别度“——事实越多，每个事实能分到的”独立性”越小
  • 减去 $\Delta a$（查询偏心的代价）、$2\eta$（噪声）、$2\varepsilon$（簇内散度）
  • 还大于 0 → 未覆盖的事实一定比冗余候选更突出

这四条假设在真实数据上成立吗？ 见「数据怎么样」第六节。结论是：条件 4 在最宽松的设置下也只有约一半的题成立，到 P=200 的候选池时基本归零——而它恰恰是 Proposition 1 归纳证明的地基。

18. 可迁移点

① “集合效用 → 重构残差”这个转换

把”选一组证据”变成”用一组嵌入重构查询”，于是：

  • 联合评估变成可计算的凸问题
  • “冗余”和”互补”自动出现在同一个目标里

这个转换不依赖具体编码器，可以搬到任何”证据组合”问题（RAG 的证据打包、多跳证据选择、上下文压缩前的选段）。

② U_MP = 相关 − 冗余 的减法结构

把它和 MMR 对比：

冗余项
MMR$\max_{s\in S}\ \mathrm{sim}(d,s)$ —— 与任意一条已选的最大相似度
MemPursuit$f(m)^\top\hat q = \sum_j \alpha_j f(m)^\top f(m_j)$ —— 与拟合凸组合的相似度

区别：MemPursuit 用的是加权平均，不是最大值。好处是：

  • 如果某条已选记忆的权重很小，它不会过度惩罚新候选
  • 权重由重拟合自动决定，不需要手工调 MMR 那个 $\lambda$

这个”用拟合权重代替 max”的思路可以迁移到任何 MMR 类方法。

③ 可计算的最优性证书（Theorem B.2）

一句话定位：

它能修”池子里有、但排得低”，不能修”嵌入里看不见”；能修”基线弱”，不能修”基线强”；能修”集合不够散”，不能修”散得不对”。

所以它的适用边界很窄，但在那个区间里，收益是真的。 还有一个细节说明算子本身并不理想：边际增益会出现”先 0 后 1”的低谷——某条证据单独评估时贡献为 0，要等前面几条被选中、权重重新分配之后才变成正的。覆盖未满时，边际增益本不该落到 0。

这正是前向贪心 + simplex 约束的固有性质：支撑集只增不减，权重却每轮重排，于是”只有和前几条组合起来才有用”的证据永远等不到自己的那一轮。CoSaMP / Subspace Pursuit 用剪枝和回溯处理这个问题，MemPursuit 没有。所以它确实还有提升空间——但那个空间要靠改算子（回溯、前瞻、或把冗余惩罚从”绝对相似”换成”超额相似”）去拿，而不是靠调参。
